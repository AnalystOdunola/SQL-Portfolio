# 🎵 Chinook Music Store Analysis


## Overview

This project explores the Chinook Music Store database using SQL to answer business questions related to music sales, customer behavior, artists, albums, genres, and revenue performance.

The analysis demonstrates how SQL can be used to transform raw transactional data into meaningful business insights through data exploration and reporting.

## Business Problem

Music stores need visibility into customer purchasing behavior, top-performing artists, albums, and genres to improve marketing strategies, inventory planning, and revenue generation.

The objective of this project was to use SQL to analyze sales data and uncover trends that support business decision-making.

## Analysis Questions

Some of the questions explored include:

- Which artists have the highest number of albums?
- Which albums generate the most sales?
- Which genres are most popular among customers?
- Which customers generate the highest revenue?
- Which countries contribute the most sales?
- What are the overall sales trends across the business?
